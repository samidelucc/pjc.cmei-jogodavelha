# Jogo da Velha ✖ ⭕
Desenvolvido como projeto pedagógico para a Festa da Família

### Tecnologias utilizadas:
- HTML5, CSS3 e JavaScript.

### Observação Técnica:
Este projeto foi desenvolvido em arquivo único para garantir portabilidade e facilidade de execução em navegadores com a versão antiga do Webview, evitando problemas de carregamento.
